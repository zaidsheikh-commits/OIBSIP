# Exploratory Data Analysis on Retail Sales Data

## Project Overview
This project explores retail sales data using Python to identify sales trends, customer purchasing patterns, and product category performance.

## Objective
- Inspect the dataset.
- Perform descriptive statistical analysis.
- Analyse sales by product category and gender.
- Explore customer age groups.
- Examine monthly sales trends.
- Create visualisations to communicate business insights.

## Tools Used
- Python
- pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset Information
The dataset contains 1,000 transactions and 9 columns:
- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## Analysis Performed
1. Dataset inspection.
2. Missing-value and duplicate checks.
3. Descriptive statistics.
4. Product category revenue analysis.
5. Gender-based revenue analysis.
6. Customer age-group analysis.
7. Monthly sales trend analysis.
8. Data visualisation.

## Key Findings
- Electronics generated the highest revenue at 156,905.
- Clothing generated revenue of 155,580.
- Beauty generated revenue of 143,515.
- Female customers contributed 232,840 in revenue.
- Male customers contributed 223,160 in revenue.
- Customers aged 46–55 recorded the highest transaction count, with 229 transactions.
- Customers aged 18–25 had the highest average transaction amount of 500.30.
- May 2023 recorded the highest monthly revenue at 53,150.
- January 2024 contained only two transactions, so it should not be compared directly with complete months.

*Note: Monetary values are reported in the dataset's original units; the currency has not been independently verified.*

## Conclusion
This project demonstrates how exploratory data analysis can help identify retail sales patterns, compare product category performance, and understand customer purchasing behaviour.
