# Customer Segmentation Using Python

## OIBSIP Data Analytics Internship – Level 1, Task 2

### Project Overview
This project focuses on customer segmentation using Python and machine learning. The objective is to analyse customer purchasing behaviour and group customers into different segments to support targeted marketing strategies.

### Dataset
The project uses an Online Retail dataset containing customer transaction information, including customer IDs, invoice details, product quantities, prices, and transaction dates.

### Steps Performed
1. Loaded and inspected the dataset.
2. Cleaned the data and handled missing or inconsistent values.
3. Calculated average purchase value.
4. Calculated purchase frequency.
5. Estimated historical customer value.
6. Performed RFM analysis (Recency, Frequency, Monetary).
7. Standardised RFM features using StandardScaler.
8. Used the Elbow Method to determine the number of clusters.
9. Applied K-Means clustering with five clusters.
10. Created scatter plots to visualise customer segments.
11. Summarised and interpreted customer clusters.
12. Created a bar chart showing customer distribution across clusters.
13. Recommended marketing strategies for each customer segment.

### Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

### Key Findings
The K-Means model grouped customers into five clusters based on their purchasing behaviour. The analysis identified regular customers, inactive customers, loyal customers, and high-value customer segments.

### Marketing Recommendations
- Re-engage inactive customers through targeted promotions.
- Reward loyal customers with loyalty programs.
- Provide personalised offers to high-value customers.
- Use customer purchasing patterns to improve marketing campaigns.

### Conclusion
This project demonstrates how RFM analysis and K-Means clustering can help businesses understand customer behaviour, develop targeted marketing strategies, improve customer retention, and support data-driven decisions.
